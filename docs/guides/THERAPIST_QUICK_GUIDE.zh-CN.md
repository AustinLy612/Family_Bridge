# FamilyBridge 治疗师快速指南

English: [THERAPIST_QUICK_GUIDE.en.md](THERAPIST_QUICK_GUIDE.en.md)。

FamilyBridge 在两次小组之间支持您的 DBT-A 小组。**它不会被实时查看。**安全事件会留在您的队列中，
直到您打开查看；系统不会自动联系任何人。请在第一次小组中告诉家庭这一点，并向他们介绍帮助页面和
医院的联系方式。

您只能看到自己的小组。青少年和照护者的数据相互独立：只有青少年主动分享，照护者才能看到青少年
日记卡中的条目。

## 开始使用

1. 在 `/redeem` 兑换管理员给您的代码，设置用户名、显示名称、语言和密码。
2. **小组与家庭：**创建一个小组，再在其中创建家庭。
3. 在家庭页面为一名**青少年**生成一个代码，为一名或多名**照护者**各生成一个代码。每个代码只显示
   一次：请复制后直接交给本人。每个人在 `/redeem` 兑换自己的代码，并各自完成知情同意。
4. 忘记密码：打开家庭页面，为该成员生成**重置代码**。

## 每周流程

| 页面 | 操作 |
|---|---|
| **安全事件队列** | 最先查看。确认新事件、复查、添加备注，并在填写后续措施后标记为已解决。也可以手动记录事件。 |
| **日程** | 设置每周期望的日记天数和各角色的家庭作业。参与者只看到"已完成"或"还没有"，不会显示逾期。记录每次小组教授了哪些技能，青少年随后会收到相应的小组回顾课程。 |
| **日记卡查看** | 选择家庭。每个人有独立的面板，显示趋势、技能使用和条目。打开会被审计。 |
| **进展** | 每个人练习过的技能覆盖图，没有总分或排名。 |
| **学习回顾**（在家庭页面） | 课程摘要、签到状态和情绪。参与者自己写的文字只在您请求时才显示，并会被审计。 |
| **内容审核** | 将缓存的 AI 讲解和测验标记为"已审核"或"需修改"。"需修改"会撤下该内容。 |
| **指标** | 入组、相对期望的日记完成情况、作业、学习、安全事件确认时间。在此按时段填写招募数字（筛查、符合条件、接触、同意）。 |

## 共同活动

1. 在家庭页面，当您认为合适时，将这对亲子标记为**适宜**。
2. 在**共同活动**页面，邀请他们在某个时间段内（最长 14 天）参加一个剧集。
3. 每个人各自回答。如果有一人选择不参加，另一人只会看到"这次活动不进行了"；不会询问或显示原因。
4. 活动期间，看板**只显示步骤进度**，不显示他们写的内容。
   - **暂停**会让双方同时暂停，任何一方都可以继续。
   - **我需要停下来**会锁定房间：选择停止的人会看到帮助页面，对方看到"活动暂时停下来了"。只有您可以
     **继续**或**结束**。请先与家庭沟通。
5. 结束后，摘要显示签到评分和私人反思。打开会被审计。请在活动之前告诉家庭您会看到他们的反思。

## 安全事件

- 事件来源：课程消息中的高风险表达（课程停止并打开帮助页面）、达到或超过站点阈值的日记冲动评分、
  令人担忧的日记备注、共同活动中的"我需要停下来"，以及您手动记录的事件。
- 参与者会看到帮助页面，其中列出医院的联系方式和值守时间。系统**不会**告诉他们有人已收到提醒。
- 请遵循医院的风险处理流程。FamilyBridge 不能替代该流程。

## 参与者永远看不到的内容

分数、连续打卡、徽章、排名、"失败"或逾期提示，或其他人的私人条目。应用内没有消息功能。
