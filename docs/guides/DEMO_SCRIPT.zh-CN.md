# 共创演示脚本

供与青少年、照护者和临床人员开展共创活动的主持人使用。English: [DEMO_SCRIPT.en.md](DEMO_SCRIPT.en.md)。
约 45 分钟。展示的所有内容都是虚构的。

内容包括：**配对、私密与分享、共同活动、重新连接、角色切换、完成，以及出错后的恢复。**

## 活动之前

1. 在全新的数据库上启动（`docker compose up -d --build`），然后填充演示数据（在 `backend/` 下）：

   ```bash
   .venv/Scripts/python -m app.cli seed-demo
   ```

   用户名和密码保存在 `seed_output/demo_credentials.json`（已被 git 忽略）。不要把这个文件显示在
   屏幕上，也不要放进幻灯片或笔记。
2. 打开**三个互不共享 Cookie 的浏览器窗口**（例如三个浏览器配置文件，或者一个普通窗口加上两个来自
   不同浏览器的无痕窗口）。每个窗口只登录一个账号，并在屏幕上标明：

   | 窗口 | 账号 | 身份 |
   |---|---|---|
   | T | `demo-therapist` | 林医生（治疗师） |
   | A | `demo-teen-a` | Maple（青少年） |
   | C | `demo-carer-a` | Maple 的妈妈（照护者） |

3. 在每个账号的**设置**中选择与听众相符的语言。每个账号登录后都会先进入**门户**；从门户或侧边栏
   打开**家桥**（小组、日记卡、共同活动）或**个人学习**（课程）。“获取帮助”始终在页面顶部。
4. 开场时说明：*"这是一个原型，里面的人都是虚构的。它不会被实时查看。今天如果有任何内容让你觉得
   不舒服，你可以随时停下来。"*

> 演示时**不要**输入真实的风险表达。请按照下面的步骤进行。

## 1. 配对（5 分钟）

展示一个家庭是如何建立的。没有人可以自行注册。

1. **T → 小组与家庭：**打开演示小组和家庭 A。说明青少年和照护者是两个独立的人，各有自己的账号。
2. **T：**展示为照护者**生成代码**（不要兑换）。说明：代码只显示一次、只能使用一次并且会过期；每个人
   在 `/redeem` 兑换自己的代码，并各自完成知情同意。
3. **T：**在家庭 A 中展示这对亲子的共同活动状态为**适宜**。治疗师标记为适宜之前，共同活动保持关闭。

*讨论问题：*"家庭应该怎样拿到他们的代码？"

## 2. 私密与分享（10 分钟）

1. **A → 谁能看到我的数据：**一起阅读列表。除非 Maple 主动分享，否则照护者什么也看不到。
2. **A → 日记卡 → 新记录：**用虚构的数值填写几项，点击**保存记录**。
3. **C → 日记卡：**显示没有任何内容被分享。
4. **A：**在已保存的记录上选择**分享**，勾选两个条目和 Maple 的妈妈，然后点击**预览**。说明预览的
   内容就是将要发送的全部内容。确认**分享**。
5. **C：**刷新页面，只出现这两个条目，没有其他内容。
6. **A：**点击**停止分享**。**C：**刷新页面，条目立即消失。

*讨论问题：*"你会想分享什么？在什么时候分享？"

## 3. 共同活动与角色切换（10 分钟）

1. **T → 共同活动：**为家庭 A 安排演示剧集，时间段选今天。
2. **A** 和 **C → 共同活动：**各自回答邀请，点击**好的，参加**。（说明：如果任意一方选择
   **这次不参加**，另一方只会看到"这次活动不进行了"，没有任何原因。）
3. **A** 和 **C：**点击**进入**，然后点击**我准备好了**。在窗口之间切换，让大家看到同一步骤的两种
   视角。
4. **私密选择：**在选择步骤中，**A** 做出选择并点击**选好了**；**A** 看到"正在等你的家人选择。"然后
   **C** 做出选择。直到这时，双方的选择才同时显示给两个人。
5. **T：**一直显示看板：它**只显示步骤进度**，不显示任何人的选择或文字。
6. **暂停：****C** 点击**暂停**，双方同时暂停。**A** 点击**继续**。

## 4. 重新连接（5 分钟）

1. **A：**在某一步中刷新页面。页面显示"正在重新连接……你的进度已保存。"并回到同一步。
2. **A：**关闭窗口。**C** 看到家人的连接已断开、位置已保存的提示。大约一分钟后
   （`ROOM_DISCONNECT_PAUSE_SECONDS`），房间会自动暂停。
3. 重新打开窗口 A，如有需要重新登录，进入**共同活动**并点击**进入**。任意一方点击**继续**，房间从
   同一步继续。

## 5. 完成（5 分钟）

1. 在 **A** 和 **C** 中完成剩下的步骤。双方都看到"你们一起完成了。"
2. **T → 共同活动：**打开摘要。摘要显示签到评分和私人反思。请明确说明治疗师能看到反思，而且打开
   摘要会被记录。

## 6. 出错后的恢复（10 分钟）

1. **拒绝：**再安排一次活动；**C** 选择**这次不参加**。**A** 只看到"这次活动不进行了"。
2. **"我需要停下来"：**再安排并开始一次活动。**A** 点击**我需要停下来**。
   - **A** 看到帮助页面（联系方式和值守时段；演示中为占位内容）。
   - **C** 看到"活动暂时停下来了"；双方都无法自行继续。
   - **T：**看板显示房间已锁定，**安全事件队列**中出现一个低严重度事件。**T** 在"沟通之后"点击
     **继续**，或点击**结束**。
3. **AI 兜底**（仅限 `LLM_PROVIDER=mock`）：在 **A** 的课程中发送一条包含 `[[mock:rule-violation]]`
   的消息。被拦截的句子不会出现，取而代之的是经过审核的文字。
4. **网络中断：**在窗口 **C** 中断开网络几秒钟，然后恢复。房间会重新连接到同一步。

*讨论问题：*"当你需要停下来时，接下来应该发生什么？谁应该知道？"

## 活动之后

- 在三个窗口中都退出登录，关闭无痕窗口。
- 演示中用过的代码和共同活动不能再次使用。下一次活动请从全新的数据库和 `seed-demo` 重新开始。
- 在共创笔记中记录反馈。不要在应用中记录参与者的姓名。
